# Aplicação HTML + LESS + JavaScript

Este projeto foi criado como exercício usando:
- **HTML** para a estrutura
- **LESS** para estilização
- **JavaScript puro** para interatividade

## Funcionalidades

- resumo com estatísticas do projeto
- tabela com histórico de versões
- busca em tempo real
- ordenação por data e versão
- layout responsivo

## Estrutura

- `index.html`
- `css/main.css`
- `js/app.js`
- `less/_variables.less`
- `less/_mixins.less`
- `less/_base.less`
- `less/_layout.less`
- `less/_table.less`
- `less/_responsive.less`
- `less/main.less`

## Recursos LESS utilizados

- **Variáveis**: cores, espaçamentos, fontes e bordas
- **Divisão dos arquivos**: estilos separados por responsabilidade
- **Escaping**: usado em `grid-template-columns` com `~"..."`
- **Mapas**: usado em `@theme` e `@spaces`

## Como executar

Basta abrir `index.html` no navegador.
